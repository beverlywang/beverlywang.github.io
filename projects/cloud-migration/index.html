Application Mobility Services

Summary

Challenge Large enterprises struggled to manage data across hybrid cloud environments. The core obstacle was simplifying the transition from on-premises systems to cloud infrastructure — without downtime or lost trust.

Role & Team Lead Designer; collaborated with Product Management, Engineering, UX Research, and Technical Content Writers.

Solution & Outcome Designed a guided, monitorable application migration experience. The product launched in July 2023 and earned a "WOW" Award. It significantly improved data migration efficiency and shaped future product strategy — with plans to add deployment capabilities and integrate into Veritas' Alta platform.

Context

Veritas InfoScale traditionally provided on-premises high-availability solutions. As existing customers migrated to cloud environments, the company wanted to help them transition smoothly — maintaining security and zero downtime, and in doing so building customer loyalty and trust.

Understand users' needs and pains

I dug into how enterprise IT teams actually move workloads to the cloud, and a few pains surfaced repeatedly:

  • The current migration process is very manual.
  • Migration tools typically focus on virtual machines rather than applications — missing the dependency configurations that keep an app working.
  • IT teams wanted multi-cloud management capabilities, not a single-provider tool.
  • A real knowledge gap existed around cloud management skillsets.

How Might We

  • How might we make the migration process easier?
  • How might we help reduce the knowledge gap?
  • How might we help users find application dependencies?
  • How might we let users manage and migrate data across different cloud providers?

Ideation process

I proposed product concepts through rapid prototyping and led stakeholder discussions to pressure-test and iterate on the direction.

Solution 1: Guided migration

Step-by-step guidance and relevant information along the migration process can empower users and boost their confidence to complete the task.

Solution 2: Monitor migration

Visualizing data-mobility activity on dashboards lets users track all migration tasks centrally, across different cloud providers — reducing the need for specialized cloud expertise.

Design process — exploration I researched broadly: across Veritas products, competitors' solutions, and non-tech domains like human-migration mapping.

Design process — initial concepts Although standard charts could represent the data, I created map-based interaction concepts to add a "WOW" factor for the new product — a direction stakeholders embraced. I started with low-fidelity wireframes to nail structure and flow before layering in visual detail.

Solution 3: Application dependencies

A clear visualization of application dependencies gives users better visibility by default. Reminders alert them when they forget to select related applications within the same cluster — supporting more accurate migration decisions.

User Testing

I ran two rounds of testing:

  • Round 1 — low-fidelity prototypes with 6 internal participants.
  • Round 2 — high-fidelity interactive prototypes with 5 external customers.

While feedback from customers was generally positive, there were still areas to improve. Priorities included updating terminology and consolidating the data-center views.

Final Deliverables

After four months of design work, I delivered comprehensive workflows — datacenter management, application discovery, migration planning, dashboards, user management, onboarding, and navigation. Following engineering implementation, I conducted UX readiness reviews.

Outcome

The product launched in July 2023, significantly reducing customer migration challenges. The map design was adopted in Veritas' flagship Alta platform. I received recognition for product innovation and continue to lead next-phase development.
