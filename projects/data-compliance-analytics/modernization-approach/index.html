Modernization Approach

The strategic disagreement that set the foundation

Data Insight was running on an outdated AngularJS stack. Customers were flagging it as a security vulnerability and the business risked losing them if modernization didn't happen fast.

But the harder problem wasn't technical — the PM and I disagreed on how to move. They proposed embedding the new design system into the existing application. I believed that would quietly break the product's credibility.

I was the only designer on this. I had to make my case and make it stick.

Two approaches. One chance to get it right.
